# Home navigation

Home is no longer a cube or a galaxy. See **[home-nav.md](home-nav.md)**
for Super Clean Home (Obsidian field, left-label stack, Diavlo focus,
SET → Options). Rainmeter is an optional addon, off by default.

C# types remain in the `Cube*` / `HomeGalaxy` names so the WinUI host
and tests stay stable. The WebView still loads `Assets/Cube/index.html`.
